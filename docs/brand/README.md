# Rastro — kit de identidade visual

O sistema visual de Rastro traduz caminhos, conexões e evidências em uma linguagem leve e humana. A base é clara; azul, lima e coral entram como sinais de navegação e decisão.

## Masters

- `public/brand/logos/rastro-lockup-dark.svg`: logo para superfícies claras.
- `public/brand/logos/rastro-lockup-light.svg`: logo para superfícies escuras.
- `public/brand/marks/rastro-mark.svg`: símbolo compacto.
- `public/brand/visual/*.svg`: grafismos vetoriais mestres.
- `public/brand/png/*.png`: exportações transparentes para sites, slides e mockups.

## Uso dos grafismos

- Use no máximo um grafismo grande e um pequeno por composição.
- Preserve as proporções e as cores originais.
- Permita cortes nas bordas; não achate nem estique.
- Mantenha o fundo predominantemente creme ou branco.
- Não adicione sombras, contornos ou gradientes aos masters.
- Não use os grafismos como substitutos do logo.
